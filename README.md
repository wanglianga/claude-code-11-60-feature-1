# 应急调度合成数据演练台

面向应急调度培训团队的**本地**合成数据生成与质量验证工具：从去标识化历史事件中生成可重复的练习数据，保留报警、派车、到场、结案之间的有效关系，不把原始个案复制到培训环境。

- 技术栈：React 18 + TypeScript + Vite；IndexedDB（Dexie）本地持久化；WebWorker 执行生成与核验
- 纯前端本地应用，**不调用任何外部服务**；无后端，故不提供 Swagger/OpenAPI
- 随题样例：`public/samples/emerg-2025-09/`（r1 首批登记 + r2 迟到源修订），覆盖并发派车、多级转运、罕见组合、跨午夜任务
- 地理场景样例：`public/samples/geo/scenarios.json`（本地平面米制坐标的“训练城”：主河/支流、桥隧、行政区、粗粒度来源区域、人口格、站点、训练时段与多个路网版本），用于替代位置生成

## 功能地图

| 模块 | 说明 |
| --- | --- |
| 来源批次 | 登记批次：实算每个文件 SHA-256 并与 batch.json 声明比对；登记字段含义与修订号；批次内容按修订不可变，运行中的任务继续引用启动快照，迟到修订另起运行 |
| 关系规则 | 事件/派遣/资源/到场/结案的引用与先后约束；车辆占用按实际任务区间 `[派遣, 到场+周转]` 以绝对毫秒核验，**跨午夜不算日期倒序**；审批后不可原地改，再编辑自动派生新版本 |
| 生成方案 | 记录要保留的全局事件类型、时长分布与随机种子；乐观锁保存——两管理员并发保存同一方案时展示冲突字段；审批门禁拒绝未审/宽松规则 |
| 生成运行 | 固定来源与规则快照，输出全新标识的多表演练包；两条路线可选（约束驱动条件采样 / 分布学习+批量抽样+约束筛选），均满足同一关系规则 |
| 质量核验 | 约定的总体统计比对、引用完整性、资源占用、时间可行性；直接标识扫描、源记录近乎复制、导出字段独特组合；两路线同一核验 |
| 发布清单 | 由输入计算产生，可回查来源批次（修订+文件哈希）、规则、运行参数（方法/种子/规模）与核验结果，支持重新校验与导出 |
| 替代位置 | 把主任务样例的**粗粒度来源区域**解释为覆盖真实原点的几何范围：在区域内找与道路图连通的可能起点，计算候选点到整个可能来源集合的最小直线距离下界、以及可能起点→派遣站点的道路行程时间范围；只有距离下界达到隐私门槛且与来源行程范围的最坏差值在容差内才标为可生成。信息不足时输出不可验证/不可生成及原因，绝不以区域中心或人口权重中心冒充原点；训练包只含合成点、粗化距离下界与区间，不含原始点或可反推原点的细粒度距离 |

## 测试账号

本工具为纯本地应用，**无后端账号体系、无需登录**。页面左下角的操作员选择（管理员A / 管理员B）仅作为本地身份标记，用于演示审批签名与「两人并发保存同一方案」的冲突处理。

## 操作与验证路径（建议顺序）

1. **来源批次** → 点「加载随题样例 r1」：查看文件哈希实算结果、字段含义表；点「源数据体检」可见 r1 中 2 条缺失到场、3 条结案时间异常（迟到修订素材）。
2. **关系规则** → 「新建标准规则」→ 检查约束后「审批」。
3. **生成方案** → 「新建方案」自动从批次学习分布 → 选择生成路线（界面有两路线适用条件说明）→ 保存 →「批准」。可尝试把容差改到系统边界外（如类型占比容差 50pp）再批准，会被门禁拒绝；引用未审批规则同样被拒绝。
4. **生成运行** → 对方案「开始生成」（WebWorker 进度条）→「查看输出」预览五张表、导出 CSV。
5. **质量核验** → 对运行执行核验：总体统计比对、引用完整性、资源占用（跨午夜安全）、时间可行性、直接标识、近乎复制、独特组合，附风险提示与核验范围声明。
6. **发布清单** → 生成清单后「回查视图」看 批次→规则→运行→核验 全链路哈希，「重新校验」逐项重算比对，可导出 JSON。
7. **迟到源修订演示** → 回到「来源批次」加载 r2：r1 标记「已被取代」；已完成的运行仍引用 r1 快照（运行记录中有提示），新运行默认使用 r2。
8. **并发冲突演示** → 两名操作员先后编辑同一方案：先保存者成功，后保存者看到冲突字段对照表（你的值 vs 库中当前值），可选择覆盖或放弃重载。
9. **替代位置**（隐私保护的可达性位置生成） →
   - 选择地理场景与「路网/站点/区域版本」；
   - 事件输入可选「场景内置样例事件（覆盖验收场景）」或「来源批次的粗粒度行政区 → 来源区域」；
   - 点「生成训练包」（WebWorker）→ 在训练包记录中「核对」，逐条查看可能起点集合规模、距离下界、来源行程区间、候选行程、最坏差值、拒绝原因与合成点；
   - 勾选「内部审计」可见可能起点/原始距离/候选评估数（**仅供本机核对**）；「导出训练包」只导出合成点、粗化距离下界与区间，不含原始点；
   - 切换 v1→v2（封路/封桥）→ v3（站点迁移）→ v4（区域修订）重新生成：同名事件的可生成状态、行程区间或包哈希会随版本变化，记录中显示版本标签与输入哈希。

## 自动化验证（本题实际执行过）

```bash
npm test     # vitest：61 个测试全部通过（含替代位置 28 个）
npm run build # tsc + vite 构建通过
```

`npm test` 覆盖：

- **跨午夜占用**：23:52 派遣、次日 00:10 到场不算日期倒序；同车跨午夜区间重叠会被检出（`tests/constraints.test.ts`）
- **先后约束**：到场早于派遣判为不可能的处置顺序；引用完整性（缺失结案/悬空引用）
- **两条生成路线端到端**（`tests/pipeline.test.ts`，使用随题样例 r2 真实驱动）：
  - 约束驱动与分布+筛选各生成 300 事件，`checkAll` 关系规则违例为 0
  - 两路线均通过同一质量核验（结论非 FAIL；罕见组合与边界相似度按设计产生 WARN 级风险提示）
  - 同一种子输出哈希完全一致（可复现），不同种子输出不同；合成标识与源标识零重叠
- **隐私核验**：真实手机号/身份证模式命中、源脱敏值逐字复制命中、合成令牌不命中；近乎复制分级；独特组合 k 阈值
- **并发与门禁**：乐观锁冲突字段清单、强制覆盖、未审规则/宽松容差被审批门禁拒绝（`tests/conflict.test.ts`，fake-indexeddb）
- **替代位置（隐私保护且保持响应可达性）**（`tests/location.test.ts`、`tests/locationService.test.ts`，逐场景核对）：
  - **可能原点集合**：区域内与道路图连通、可由派遣站点到达的可能起点；起点集合规模不足 k 时 `PRIVACY_SET_TOO_SMALL`（稀疏乡村单节点）
  - **距离下界**：候选点到整个来源区域（覆盖真实原点的几何范围）的最小直线距离，按桶向下取整发布；中心城区、跨河村落均校验发布值 ≥ 门槛且与几何距离一致
  - **行程时间范围与最坏差值**：可能起点→站点行程区间 `[lo,hi]`，候选行程的最坏差值 `max(|c-lo|,|c-hi|)`；自洽且 ≤ 容差才可生成
  - **拒绝原因**：区域跨越路网断点 `NO_CONNECTED_ORIGINS`；封桥后跨支流村落失去可达路径 → 不可生成；区域缺失 `REGION_MISSING`、站点缺失 `STATION_MISSING`、版本缺失 `NETWORK_VERSION_MISSING` 均判不可验证且不输出合成点
  - **版本化**：v1→v2（封路/封桥）、v3（站点迁移）、v4（区域修订）产生不同版本标签与包哈希；包哈希可复现
  - **发布内容**：发布包白名单校验，不含 `possible_origin_node_ids` / `privacy_distance_raw_m` / 原始点；距离下界为桶的整数倍、合成点落在网格上
  - **两种策略**：road-node（路网节点抽样，路径语义真实）与 area（行政区/人口带构造面，代表性较好但细长/跨河常无合格点）均通过同一门槛/容差校验

另实际执行过：`npm run build` 构建通过；`vite preview` 下 `/`、`/samples/geo/scenarios.json` 与 `/samples/emerg-2025-09/r1|r2/*` 均返回 200。Docker 镜像构建未在本环境执行（环境无 docker 命令），Dockerfile 与 compose 配置已提供且与 `npm run build` 产物一致（nginx 托管 dist）。

## 复现说明

同一「方案 + 批次快照 + 规则版本 + 种子」必然产生同一演练包：发布清单记录了全部输入哈希（批次文件、规则、方案参数、输出表、核验报告），在「发布清单 → 重新校验」可逐项重算比对。

替代位置训练包同样可复现：同一「地理场景 + 路网版本 + 生成配置（策略/门槛/容差/k/桶宽/网格/种子）+ 事件输入」必然产生同一训练包，包哈希由场景、输入哈希（路网/站点/区域/时段）、配置与全部条目计算；任一道路图、站点或来源区域修订都会改变版本标签与包哈希。`npm run gen:geo` 可确定性重建地理场景样例。

## 风险核验范围声明

基础风险核验只覆盖：①导出字段中的直接标识（模式匹配 + 源值逐字比对）；②与源记录的近乎复制；③已声明字段组合的独特性（k 阈值）。**不宣称能抵御针对特定目标的定制攻击**、背景知识链接或组合推断；演练包应按内部受控资料管理。

## 目录结构

```
src/domain/     纯领域逻辑（生成器A/B、约束、统计、隐私、核验、清单、冲突；替代位置：geo/locationEngine/locationPackage）
src/services/   编排层（批次登记、运行/核验 Worker 编排、清单、导出；替代位置生成编排）
src/workers/    WebWorker 入口（生成 / 核验 / 替代位置）
src/pages/      八个页面
src/db/         Dexie（IndexedDB）schema
public/samples/ 随题样例（r1 + r2 迟到修订，含 batch.json 声明哈希与 fields.json 字段字典）
public/samples/geo/  地理场景样例（训练城：路网/河流/行政区/来源区域/人口格/站点/版本）
scripts/gen-samples.mjs        样例再生成脚本（确定性，node scripts/gen-samples.mjs）
scripts/gen-geo-scenarios.mjs  地理场景再生成脚本（确定性，npm run gen:geo）
tests/          vitest 测试
```
